01-Emmet

Plugin para codificacion mas rapida en HTML y CSS..

01-Child: >
Crea elementos hijos (anidacion).

Ejemplo

ul>li>a↔️

Resultado

<ul> <li> <a href=""></a> </li>

02-sibling: >
Crea elementos hermanos.

Ejemplo

section+header+nav↔️

Resultado

<section></section> <header></header> <nav></nav>

03-multiplicacion: *
Repeats elements multiple times.

Ejemplo

ul>li*3↔️

Resultado

<ul> <li></li> <li></li> <li></li> </ul>

04-class: .
Creates a class attribute.

Ejemplo

menu.mainmenu↔️

.container

Resultado

<menu class= "mainmenu"></menu> <div class = "container"></div>

05-classes: ...
Creates multiples class attributes.

Ejemplo

menu.mainmenu.uppercase.blue↔️

Resultado

<menu class= "mainmenu uppercase blue"></menu>

06-Identificacion: #
Creates an id attributes.

Ejemplo

nav#navigation123↔️

Resultado

<nav id= "navigation123"></nav>

07-texto: {}
Insert text content.

Ejemplo

p{Lorem Ipsum Dolor.}↔️

a{Click Here}↔️

Resultado

<p>Lorem Ipsum Dolor.</p> <a href="">Click Here</a>

08-Custom Attribute: []
Creates custom attributes.

Ejemplo

a[href=www.youtube.com]↔️

Resultado

<a href="www.youtube.com"></a>

09-Item Numbering: $
Adds consecutive numbers.

Ejemplo

ul>li.item$*5↔️

Resultado

<ul> <li class="item1"></li> <li class="item2"></li> <li class="item3"></li> <li class="item4"></li> <li class="item5"></li> </ul>

10-Reverse Numbering
Invierte el orden de numeración.

Ejemplo:

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

11-Base Numbering
Define un número base para secuencias

Ejemplo:

ul>li.num$@3*4 ↔️

Resultado:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up
Sube un nivel.

Ejemplo:

section>article>div^p ↔️

Resultado:

<section> <article> <div></div> <p></p> </article>

13-Grouping
Agrupa elementos juntos.

Ejemplo:

(header>nav)+footer ↔️

Resultado:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem
Genera texto de relleno.

Ejemplo:

lorem5 ↔️

Resultado:

<p>Lorem ipsum dolor sit amet.</p>

15-HTML Documents
Crea varios tipos de documentos HTML.

Ejemplo:

html:5 ↔️

Resultado:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport"> <title>Document</title> </head> </html>

16-Meta Tags
Genera texto de relleno.

Ejemplo:

meta:vp ↔️

Resultado:

<meta name="viewport"
